# Deepfake Detection System

## Overview

The Deepfake Detection System is a machine learning and deep learning based project developed to identify whether an image is real or AI-generated (deepfake). The system uses transfer learning with EfficientNetB0 to classify facial images into two categories: Real and Fake.

This project was developed as a college mini project to explore the practical applications of Artificial Intelligence, Computer Vision, and Deep Learning in the field of media authenticity and cybersecurity.

---

# Objectives

* To detect AI-generated fake human face images.
* To apply transfer learning using EfficientNetB0.
* To improve classification accuracy using image preprocessing and augmentation.
* To understand the impact of deepfakes in modern digital media.
* To build a simple and effective deepfake detection model.

---

# Problem Statement

With the rapid growth of AI-generated media, deepfakes have become increasingly realistic and difficult to identify manually. Deepfake content can spread misinformation, create fake identities, and manipulate public opinion.

The aim of this project is to develop a deep learning based system capable of distinguishing real images from manipulated or AI-generated images.

# Deep Learning Model

This project uses EfficientNetB0 as the base model for transfer learning.

## Why EfficientNetB0?

* Lightweight and efficient architecture
* High accuracy with fewer parameters
* Good performance for image classification tasks
* Faster training compared to larger CNN models
